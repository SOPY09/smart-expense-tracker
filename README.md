# 💰 Smart Expense Tracker

A simple and efficient **C++-based expense tracking application** designed to help users record, manage, and analyze their daily expenses.

The project focuses on applying core C++ programming concepts to build a practical personal-finance management system.

## ✨ Features

* ➕ Add new expenses
* 📋 View all recorded expenses
* 🔍 Search and filter expenses
* ✏️ Edit existing expense records
* 🗑️ Delete expenses
* 📊 Track total spending
* 🗂️ Categorize expenses
* 💾 Store expense data for future use
* 📅 View expenses based on dates
* 💰 Calculate spending summaries
* 🖥️ Simple and user-friendly console interface

## 🛠️ Technologies Used

* **Language:** C++
* **Compiler:** MinGW / GCC
* **Development Environment:** Visual Studio Code
* **Data Storage:** File handling
* **Version Control:** Git & GitHub

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Smart-Expense-Tracker.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code** or any C++ IDE.

### 3. Compile

Using g++:

```bash
g++ main.cpp -o expense_tracker
```

### 4. Run

On Windows:

```bash
expense_tracker.exe
```

Or:

```bash
.\expense_tracker.exe
```

## 🎯 How It Works

The application allows users to enter information about their expenses such as:

* Amount
* Category
* Date
* Description

The data is processed by the program and stored using file handling so that expense records can be accessed again when the application is reopened.

Users can then view and manage their expenses through the application's menu-driven interface.
